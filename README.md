# Java Banking App

This is a simple banking application I built while learning Java. It runs in the console and helps users keep track of deposits, payments, and transactions.

I made this project to practice writing Java classes, working with files, and building menus that users can navigate.

## What it can do

- Add deposits and payments
- Show all transactions, deposits, or payments
- Keep track of the balance
- Save transactions in a CSV file
- Show reports for this month, last month, this year, and last year
- Search transactions by vendor name

## Tools I used

- Java
- IntelliJ IDEA
- CSV files for saving data

## How to run it

1. Open the project in IntelliJ IDEA.
2. Make sure `transactions.csv` is in the project's working directory.
3. Run `Main.java`.
4. Choose an option from the menu.

## Project files

- `Main.java` — shows the menus and handles user choices
- `Transaction.java` — stores transaction information and handles deposits, payments, and reports
- `Console.java` — reads input from the user
- `transactions.csv` — saves the transactions

## What I learned

While building this project, I practiced using classes and objects, methods, loops, `switch` statements, `ArrayList`, `HashMap`, dates, and reading and writing files.
